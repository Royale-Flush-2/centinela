## sql:
```sql
SELECT d.name AS dc,
       i.cases_available,
       s.avg_daily_sales_14d,
       ROUND(i.cases_available / s.avg_daily_sales_14d, 1) AS coverage_days
FROM dc_inventory i
JOIN dcs d ON d.id = i.dc_id
JOIN v_daily_sales s ON s.sku = i.sku AND s.dc_id = i.dc_id
WHERE i.sku = '70412'
  AND i.cutoff_at = '2026-10-02 06:00'
ORDER BY coverage_days;
```
